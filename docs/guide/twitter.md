# Twitter Gallery

The Twitter Gallery block fetches the latest media (images) from any public Twitter (X) profile and displays them in a responsive grid.

## Features
- **No API Key:** Uses a custom fetcher that doesn't require a paid Twitter API subscription.
- **Media Only:** Focuses on showing your latest visual content.
- **Privacy First:** Images are proxied through your server.

## How to Use
1. Add the **Twitter Gallery** block.
2. Enter the Twitter handle (without the `@`).
3. Set the number of columns and items to display.

::: tip Note
This block only works with public profiles. If a profile is private, the gallery will appear empty.
:::
