# RSS Gallery (Facebook)

The RSS Gallery is a versatile block that can display a media grid from any valid RSS feed. This is the recommended way to showcase Facebook Page posts.

## How to use for Facebook
1. Use an RSS bridge (like [RSS.app](https://rss.app/) or a self-hosted RSS-Bridge) to generate a feed for your Facebook Page.
2. Copy the RSS Feed URL.
3. Add the **RSS Gallery** block to your page.
4. Paste the URL into the "RSS Feed URL" setting.

## Features
- **Auto-Extraction:** Automatically searches for images in the feed's enclosures and content.
- **Universal:** Works with WordPress feeds, Blog feeds, and Social Media bridges.
